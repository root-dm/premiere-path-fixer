Pr Premiere Path Fixer
Processed in your browser

Fix broken media paths
in your Premiere project.

Premiere saves the full location of each media file inside a project. If the files move, a drive letter changes, or the project opens on another computer, those saved paths can point to the wrong place. Replace their shared path prefix to reconnect the files.

Project & paths

1 Path currently saved in the project
2 Where those files live now

For example: /Volumes/MediaDrive/Footage/clip.mp4 → D:\Footage\clip.mp4
Also works from Windows to macOS, or between two drives on the same system.
